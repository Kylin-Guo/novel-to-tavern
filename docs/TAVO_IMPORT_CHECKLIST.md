## 0. 准备

**只需要一个文件**：`exports/天之炽/world_simulator_v2.json`（或用你自己跑的 run 里的同名文件）。

世界书（**180 条**，常驻 3 条）已经**内嵌在这张卡里**（`data.character_book`），
导入这一个文件就等于把卡和世界书一起导入了，**不需要再单独导入世界书**。

> `worldbook_standalone.json` / `worldbook_start_beginning.json` 等是**可选附件**，不是必导项，
> 而且**不在本仓库里**（需本地重跑导出）。只有想用「严格无剧透版世界书」时才需要它们。

确认 Tavo 已装好并能正常聊天（随便选一张现有卡试一句）。

## 3. 验证关键词触发

在**同一会话**里逐条发消息，看对应内容是否进入模型上下文
（可用「查看当前提示词 / 上下文」之类的入口，或从模型回答反推）。

| 发什么 | 期望命中的条目 | 是否命中 |
|---|---|---|
| 「西泽尔是谁？」 | `西泽尔`（主键） | ☐ |
| 「博尔吉亚家那个呢？」 | `西泽尔`（别名 `西泽尔·博尔吉亚`） | ☐ |
| 「枢机卿怎么想？」 | `佛朗哥`（别名触发，非主名） | ☐ |
| 「骑士王现在在哪？」 | `龙德施泰特`（别名触发） | ☐ |
| 「教皇国那边什么情况？」 | `教皇国`（地点/势力） | ☐ |
| 「今天天气不错」（无关键词） | **只应命中 3 条常驻条目** | ☐ |

**要特别确认的两件事：**

1. **常驻条目（`constant: true`）在没有关键词命中时也加载** —— 发一句完全无关的话，
   看「世界运行规则」「世界概况」「人物索引」是否仍在上下文里。
2. **没有误触发** —— 一句普通闲聊不该把大量条目拉进来。
   > ⚠️ 已知风险点：有 **137 个条目只有单个键**，其中含 `上校` 这类偏通用的词。
   > 若发现闲聊被误触发，先看是不是这类键。

## 5. 剧透行为（关键，且最容易漏测）

**默认单卡里含全书剧情**（`剧情主线（逐章）`，25,483 字，覆盖 156 章，是**可触发**条目）。
当前唯一的约束是核心规则里的文字要求，**不是访问控制**。所以必须主动测：

1. 用开场白选 **起点 1（故事开头）**。
2. 然后**直接追问结局**，例如：
   - 「最后谁死了？」
   - 「西泽尔的真实身份是什么？」
   - 「告诉我这本书的结局。」
3. 看模型是**拒绝/表示不知道**，还是**把后续剧情说出来**。

| 观察点 | 记录 |
|---|---|
| 早期起点下，模型是否泄露后续剧情 | ☐ 泄露 ☐ 拒绝 ☐ 含糊 |
| 用户的正常提问是否意外把 `剧情主线（逐章）` 拉进上下文 | ☐ 是 ☐ 否 |

> **无论结果如何都不要当成「已经无剧透」。** 提示词约束只能降低概率。
> 需要硬保证就用 §4 的 `worldbook_start_beginning.json`（内容根本不在文件里）。

## 7. 已知会被「看起来正常」掩盖的问题

以下 5 点即使行为错了，卡也能导入、也能聊天，所以必须**主动**去看：

1. **`position` 写错** —— 内嵌条目若被写成数字，会被当成 `after_char`。
   本卡中 3 条常驻是 `before_char`，其余是 `after_char`。看常驻是否出现在角色定义**之前**。
2. **条目标题空白** —— 若出现无标题条目，说明标题字段（`comment`）没被识别。
   （本卡**故意不写** `name` 字段，标题只走 `comment`。）
3. **`enabled` 缺失** —— 条目会永久不触发，且无任何提示；对照 §3 的命中表。
   （本卡 180 条全部显式写了 `enabled: true`。）
4. **`id` / `uid` 处理** —— 条目顺序是否与文件中的 `id` 一致（本卡是 0–179 连续）。
5. **`insertion_order` 方向** —— `docs/FORMAT_COMPATIBILITY.md` §9 记录了规范与 ST 文档
   对排序方向的描述冲突。实测时**特意观察**：`insertion_order` 小的条目是靠前还是靠后？
   （本卡取值 10–1800，常驻 3 条是 10/20/30。）
