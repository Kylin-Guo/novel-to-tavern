## 8. 已知限制

1. **Tavo 未实测。** 官方文档无字段级说明，本项目不做任何 Tavo 专属假设。
2. **`insertion_order` 方向语义未定论**（规范与 ST 文档描述相反），条目顺序先用 ST 模板默认值。
3. **事件没有绝对时间**：`occurred_at` 恒为 `null`，原文的「次日」只作 `relative_time` 原样记录。
4. **知识边界是推断**：由「事件参与者」推出 `present_at_event`，不等于原著明文授权；
   未采用「事件发生后所有人都知道」的假设。
5. **188 条合并候选待人工复核**：名字相似但证据不足的实体对**没有**被自动合并
   （例如「西泽尔 ✕ 红龙」—— 抽取器在 31 个分块里把「红龙」记为西泽尔的别名，
   但「红龙」同时是机甲名，类别冲突，故拦下）。
6. **260 条冲突只报告未解决**：同一主语同一谓词出现多个取值，需人工判断是随时间变化还是原文矛盾。
7. **事实来自自动抽取，仅做了抽样核对**，未逐条人工审校。
