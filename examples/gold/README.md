# 黄金集：一次可复现的质量测量

这个目录补上第三种证据。项目原先只有两种：

- **302+ 项单元测试** —— 测的是代码分支对不对；
- **156 章真实跑一遍** —— 规模够，但**没有标准答案**，无法判断对错。

这里补的是：一篇**自创**的八章小说 + **手写**的抽取结果 + **手标**的期望，
端到端跑完整条流水线，算出精确率与召回率。全部离线、可复现、秒级完成。

---

## 文件

| 文件 | 是什么 |
|---|---|
| `灰港纪事.txt` | 8 章、约 2,000 字的**自创**微型小说。不含任何第三方作品内容 |
| `extraction.json` | **手写**的抽取结果，扮演 `llm.provider = file` 的预生成响应 |
| `expectations.json` | 手标期望：该有哪些实体、哪些事实、哪些冲突、哪些知识状态 |
| `../../tests/test_gold_evaluation.py` | 跑流水线并断言这些期望 |

## 它测什么，不测什么

| 测 | 不测 |
|---|---|
| 证据定位（引文能不能逐字找到） | **模型抽得好不好** —— 抽取结果是手写的 |
| 「没有证据不进 canon」这条规则是否真的生效 | 抽取的召回率（漏了什么，这里造不出来） |
| 实体归一的合并与不合并 | 真实语料里的长尾噪声 |
| 知识边界的状态判定 | 人类判断的语义正确性 |
| 起始点过滤是否真的删掉内容 | Tavo/ST 的运行时行为 |
| 同名不同人的**已知限制**被锁定 | —— |

> 一句话：**这里的数字说明管线做得对不对，不说明模型抽得准不准。**
> 两者都要有，不能互相替代。

## 微型小说的设计

刻意塞进了这些**容易出错**的情形：

1. **别名**：凌霜 / 霜姐（霜姐只在别名字段里出现，从不作为独立提及）；
2. **同名不同人**：码头的老周 vs 灯塔的老周 —— 原文明说「不是一个人」；
3. **后期揭示的秘密**：阿澜是黑帆商会的人，第 4 章才告诉读者；
4. **关系变化**：凌霜与韩铮从七年同僚到有隔阂；
5. **传闻**：酒馆里说黑帆商会的鬼魂还在雾灯塔上；
6. **角色信念**：阿澜说死者「就是个走错路的醉汉」；
7. **时间跳跃**：「三天后」「九天」「三年前」；
8. **角色缺席**：凌霜被袭击时阿澜不在场；
9. **前后矛盾**：雾灯塔的高度，阿澜说四十米、凌霜说三十米；
10. **读者先于角色知道**：第 4 章揭示，凌霜第 7 章才当面确认；
11. **故意编造的引文**：一条事实的引文在原文里根本不存在 —— 必须被挡在 canon 之外。

## 已知限制（被测试锁定）

**同名不同人会被合并。** 码头的老周与灯塔的老周在原文明说是两个人，
但归一阶段按字面同名聚类，两者会合成一个「老周」。

`test_known_limitation_same_name_different_person_is_still_merged`
**锁定当前行为**：将来若支持区分同名不同人，这条会失败，提醒维护者更新期望文件。

这是故意的 —— 已知限制要么被修，要么被钉住，不能只是写在文档里。

## 使用方式

改抽取、改归一、改时间线、改条目门槛之后，跑这一条就知道有没有破坏上述保证：

```bash
.venv/bin/python -m pytest tests/test_gold_evaluation.py
```

它的运行产物在 pytest 的临时目录里，**不写入 `runs/`**，也不进仓库。
