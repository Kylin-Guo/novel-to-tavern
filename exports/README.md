### ⚠️ 剧透提示

本卡**含全书剧情**（`剧情主线（逐章）` 条目，25,483 字，覆盖 156 章，是**可触发**条目）。
默认用法下的剧透防护靠的是核心规则里的**文字约束**，**不是访问控制** —— 模型仍可能读到后续剧情。

触发词已收窄为组合词（`原著逐章大纲` / `逐章大纲` / `原著大纲` / `全书大纲` /
`剧情主线` / `主线剧情`）：说「这个剧情怎么发展」「主线任务是什么」**不会**命中。
但子串匹配**不认识否定** —— 「我没见过西泽尔」一样会命中角色条目。

需要严格无剧透，请本地重跑：

```bash
n2t export --run-id <run_id> --start-chapter 40
```

产出的 `card_start_chapter_40.json` 里，第 40 章之后的事实**根本不在文件中**
（实测：从第 1 章开始时，180 条压到 8 条，59,946 字压到 1,211 字）。
这些严格档文件**不在本仓库**。详见根目录 [`README.md`](../README.md#剧透防护两个档位)。

重新生成：

```bash
n2t ingest && n2t extract --run-id <id> && n2t resolve --run-id <id> \
  && n2t verify --run-id <id> \
  && n2t timeline --run-id <id> && n2t export --run-id <id> --start-chapter 1
```
